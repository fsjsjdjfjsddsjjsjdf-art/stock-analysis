# BHARATQUANT: India Stock Market Day-Trader Terminal & EOD Playground

An institutional-grade, multi-module Indian Stock Market (NSE/BSE) day-trading terminal, real-time momentum scanner, interactive charting engine, risk position sizer, and daily End-of-Day (EOD) audit playground tailored for ₹ INR trading.

## Repository Structure
- `index.html`: Unified BHARATQUANT terminal application.
- `assets/style.css`: Modular CSS styles and responsive design definitions.
- `modules/scanner.js`: RVOL, VWAP, and ORB momentum scanner logic.
- `modules/chart.js`: HTML5 Canvas Candlestick & Indicator engine (EMA, VWAP, ATR).
- `modules/risk.js`: Position sizing and SEBI MIS 20% margin calculations.
- `modules/broker.js`: Zerodha Kite, DhanHQ, Upstox order payload generator & blotter.
- `modules/alerts.js`: Price, VWAP, and RSI alert rules engine.
- `modules/eod_report.js`: Daily End-of-Day EOD performance audit report & simulation.
- `modules/playground.js`: Dumb trade sandbox and suggestion tester arcade.

## How to Run Locally
1. Clone or download this repository.
2. Open `index.html` in any modern web browser.
